# NFR-005 — Make culture-sensitive parsing configurable

**Requirement:** [NFR-005](../../requirements/non-functional.md)  
**Tracking issue:** [#45](https://github.com/infoconex/RecordSift/issues/45)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-005-SC01 — Parse in an explicit non-default culture

**Given** a source contains locale-specific decimal and date strings,  
**When** a matching culture is configured,  
**Then** numeric and date values are interpreted according to that explicit culture.

## NFR-005-SC02 — Do not silently use ambient culture

**Given** identical input/settings are processed under different process cultures,  
**When** imports complete,  
**Then** equivalent typed values and validation results are returned.
