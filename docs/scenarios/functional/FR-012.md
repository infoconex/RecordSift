# FR-012 — Declare required and optional fields

**Requirement:** [FR-012](../../requirements/functional.md)  
**Tracking issue:** [#8](https://github.com/infoconex/RecordSift/issues/8)  
**Priority:** Must  
**Verification status:** Planned — legacy specification-planning metadata **only**, not current execution status. Both FR-012 acceptance scenarios are Automated with observed Windows CI evidence in [scenario-to-test traceability](../../testing/traceability.md).

## Purpose

Required and optional values must behave predictably for missing columns and empty fields.

## Functional requirement

**RecordSift shall:** Allow schemas to distinguish required fields from optional fields.

## Inputs and outputs

- **Inputs:** Requiredness metadata, source field presence, and input value.
- **Outputs:** Required-value errors where applicable; accepted missing optional values as specified.

## Functional rules

- Report missing required values as validation errors identifying their fields.
- Do not reject an otherwise valid record solely because an optional field is missing.
- Separate absent source columns from present but empty values.
- Apply default-value behavior only where explicitly defined in a separate requirement.

## Dependencies and scope

- **Related requirements:** [FR-009](FR-009.md), [FR-015](FR-015.md), [FR-017](FR-017.md).
- **Boundary:** Optional defaults are a Should feature (FR-015), not implicit in requiredness.

## Open design decisions

Define how whitespace-only strings, empty quoted fields, and nullable value types are treated.

## Acceptance scenarios

### FR-012-SC01 — Distinguish missing required and optional values

**Given** a record has no required value and no optional value,  
**When** validation runs,  
**Then** only the missing required field is reported invalid.

### FR-012-SC02 — Allow an absent optional field

**Given** a source omits a schema-optional column,  
**When** schema binding and import occur,  
**Then** import succeeds for otherwise valid records without manufacturing a required-field error.
