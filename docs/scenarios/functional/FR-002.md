# FR-002 — Import XLSX workbooks

**Requirement:** [FR-002](../../requirements/functional.md)  
**Tracking issue:** [#6](https://github.com/infoconex/RecordSift/issues/6)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## Purpose

Organizations need to validate tabular workbook data without installing Excel.

## Functional requirement

**RecordSift shall:** Read supported `.xlsx` cell data as logical records suitable for the common import pipeline.

## Inputs and outputs

- **Inputs:** An XLSX workbook source, schema, and worksheet-selection option.
- **Outputs:** Records with worksheet/row provenance or a classified source-level error.

## Functional rules

- Import stored cell data without automating Excel.
- Maintain record order within the selected worksheet.
- Preserve worksheet name and source row coordinates for diagnostics.
- Report corrupt or unreadable workbooks as source failures, not successful zero-row imports.

## Dependencies and scope

- **Related requirements:** [FR-005](FR-005.md), [FR-009](FR-009.md), [FR-026](FR-026.md), [FR-028](FR-028.md), [NFR-003](../non-functional/NFR-003.md), [NFR-008](../non-functional/NFR-008.md).
- **Boundary:** Editing workbooks, executing macros and formula recalculation are out of scope.

## Open design decisions

- Read only the first workbook worksheet by workbook order when no explicit selector is supplied; FR-005 will add explicit selection.
- The first nonblank physical worksheet row is the header. Exact, ordinal header names use the established Domain binder; nonblank records appear in source order.
- Skip completely blank rows. Preserve physical worksheet row numbers for every retained row. An empty worksheet fails with `REQUIRED_HEADER_MISSING`; a header-only worksheet completes with no records.
- Missing and merged continuation cells are empty strings. Only the merged anchor has a stored value.
- Numeric values use invariant decimal text; date values use invariant ISO 8601 round-trip text. Existing Domain converters control typed property mapping.
- Read formula cached values when the reader exposes them, without evaluating formulas. A formula without a cached value is treated as a blank value. Macro execution and external data refresh are unsupported.
- Corrupt or invalid packages produce `MALFORMED_SOURCE`; IO failures produce `SOURCE_UNREADABLE`; exceeded compressed/uncompressed, row, column or cell budgets produce `SOURCE_LIMIT_EXCEEDED`.
- Reject workbook packages with explicitly recognized external-link or VBA payload parts. There is no Excel/COM dependency. Known complex content not supported by the parser is rejected, not represented as an empty successful workbook.
- The caller owns the input stream. Per-call `maxBytes` and optional `XlsxReadLimits` constrain input bytes, rows, columns and cell text. The Infrastructure reader additionally bounds ZIP entries and declared decompressed bytes. Resource enforcement is defense in depth, not a formal guarantee against all malicious ZIP structures.

See [ADR 0032](../../engineering/decisions/0032-xlsx-reader-shared-validation.md).

## Acceptance scenarios

### FR-002-SC01 — Read a valid worksheet

**Given** an XLSX fixture contains typed customer data and a matching schema,  
**When** the workbook is imported,  
**Then** records are typed correctly and preserve worksheet name and row provenance.

### FR-002-SC02 — Reject an unreadable workbook

**Given** the provided file is not a valid XLSX workbook,  
**When** import is attempted,  
**Then** a source-level failure is reported without presenting a successful empty import.
