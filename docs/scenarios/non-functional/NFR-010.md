# NFR-010 — Protect observable public API compatibility

**Requirement:** [NFR-010](../../requirements/non-functional.md)  
**Tracking issue:** [#50](https://github.com/infoconex/RecordSift/issues/50)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — the future cross-framework comparison has not been performed. The existing .NET Framework 4.8 baseline checks are Automated and evidenced in the traceability matrix.

## NFR-010-SC01 — Compare public surface across modernization

**Given** a baseline API contract and package metadata are captured,  
**When** a project/SDK modernization change is proposed,  
**Then** unintended public API and package shape changes are detected by automated or reviewed comparisons.

## NFR-010-SC02 — Preserve validation JSON behavior

**Given** a pre-modernization validation report snapshot exists,  
**When** a dependency or framework upgrade is evaluated,  
**Then** unintentional diagnostic and serialization differences are flagged before release.

## Verification notes

Follow the [testing strategy](../../testing/strategy.md). Record the executable test or reviewed procedure and observed evidence separately for each scenario in [traceability](../../testing/traceability.md). Scenarios for future modernized targets cannot be declared verified on the initial .NET Framework baseline.

## Release 0.1 baseline evidence

[PR #151](https://github.com/infoconex/RecordSift/pull/151) creates [the compiled public surface baseline](../../compatibility/public-api-net48.txt) and seven golden JSON fixtures under `tests/RecordSift.Infrastructure.Reporting.Tests/Fixtures/Compatibility/`. [Windows CI #41181906001](https://github.com/infoconex/RecordSift/actions/runs/41181906001) passed 278/278 NUnit tests and verified 375 public API/metadata entries from all five net48 Release assemblies, including a negative tampered-baseline check. [Documentation #41181905950](https://github.com/infoconex/RecordSift/actions/runs/41181905950) passed.

**Modernization remains a separate future verification obligation.** These runs establish the comparison gate and pre-modernization artifacts; they do not claim that an actual framework or SDK migration was compared.
