# FR-028 — Return invalid-record diagnostics

**Requirement:** [FR-028](../../requirements/functional.md)  
**Tracking issue:** [#29](https://github.com/infoconex/RecordSift/issues/29)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## FR-028-SC01 — Identify failed records and fields

**Given** an imported row violates a declared validation rule,  
**When** import completes,  
**Then** a structured diagnostic identifies the source, logical row, field and error code.

## FR-028-SC02 — Report multiple independent failures

**Given** one row violates two independent validation rules,  
**When** validation runs,  
**Then** both failures are available without incorrectly counting two rejected rows.
