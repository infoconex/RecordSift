# FR-001 — Import CSV files

**Requirement:** [FR-001](../../requirements/functional.md)  
**Tracking issue:** [#2](https://github.com/infoconex/RecordSift/issues/2)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## Purpose

Teams regularly receive comma-separated business data and need a reliable import entry point before domain validation can begin.

## Functional requirement

**RecordSift shall:** read a CSV data source as a sequence of logical records suitable for schema mapping and validation.

## Inputs and outputs

- **Inputs:** A CSV source, schema definition, and reader configuration.
- **Outputs:** Parsed logical records integrated with the standard typed import result, or a classified source failure.

## Functional rules

- Respect CSV quoting so delimiters and embedded newlines inside quoted fields do not create extra records or columns.
- Preserve logical record order and do not silently discard source rows.
- An empty CSV source is a completed zero-record import, unless a separately configured schema requirement is violated.
- Distinguish malformed CSV source structure from individual field-validation errors.

## Dependencies and scope

- **Related requirements:** [FR-003](FR-003.md), [FR-004](FR-004.md), [FR-006](FR-006.md), [FR-009](FR-009.md), [FR-026](FR-026.md), [FR-028](FR-028.md), [FR-029](FR-029.md).

## Open design decisions

## Acceptance scenarios

### FR-001-SC01 — Import a valid CSV file

**Given** a CSV fixture has three valid customer records and a matching schema,  
**When** the CSV file is imported,  
**Then** three correctly typed records are accepted in original order with no validation errors.

### FR-001-SC02 — Import an empty CSV file

**Given** a CSV file contains no data records,  
**When** the CSV file is imported,  
**Then** zero records are returned and the completed summary reports zero processed records.

### FR-001-SC03 — Report malformed CSV quoting

**Given** a CSV file has malformed quoting,  
**When** import is attempted,  
**Then** a structured parsing failure identifies the source and any reliable location information.

### FR-001-SC04 — Preserve quoted values

**Given** a CSV record contains a delimiter or newline inside a properly quoted field,  
**When** the record is imported,  
**Then** the quoted field is parsed without splitting its content into extra columns or records.
