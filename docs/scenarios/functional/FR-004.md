# FR-004 — Support CSV with and without headers

**Requirement:** [FR-004](../../requirements/functional.md)  
**Tracking issue:** [#14](https://github.com/infoconex/RecordSift/issues/14)  
**Priority:** Must  
**Verification status:** Planned — raw CSV reader/header-policy component tests exist; complete typed import acceptance is unverified.

## Purpose

Both headed and positional CSV feeds must be usable without accidentally dropping data.

## Functional requirement

**RecordSift shall:** Support CSV files with and without a header row using an explicit header policy.

## Inputs and outputs

- **Inputs:** CSV data, a headed/headerless mode, and corresponding name or position mappings.
- **Outputs:** Records bound correctly, with logical data-record numbers excluding any header.

## Functional rules

- In headed mode, treat the first source row as header metadata.
- In headerless mode, treat the first source row as data.
- Report missing required headers as schema binding failures.
- Do not silently infer a header and discard the first data row.

## Dependencies and scope

- **Related requirements:** [FR-001](FR-001.md), [FR-009](FR-009.md), [FR-013](FR-013.md).
- **Boundary:** Header aliases are handled by FR-014 rather than this requirement.

## Open design decisions

Resolved for the raw header-policy layer by [ADR 0006](../../engineering/decisions/0006-csv-header-policy.md): explicit headed/headerless modes, FR-009's ordinal case-sensitive matching, blank headers not bound, duplicate declared headers are ambiguous. No automatic inference.

## Acceptance scenarios

### FR-004-SC01 — Import headed and headerless files

**Given** matching CSV fixtures contain headers or positional data,  
**When** the corresponding header policy is configured,  
**Then** both files import all data records without dropping the first headerless row.

### FR-004-SC02 — Reject a missing declared header

**Given** header-based mapping requires a column absent from the CSV header,  
**When** import starts,  
**Then** the missing-column condition is reported without silently shifting values.
