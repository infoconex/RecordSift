## NFR-010-SC01 — Compare public surface across modernization

**Given** a baseline API contract and package metadata are captured,  
**When** a project/SDK modernization change is proposed,  
**Then** unintended public API and package shape changes are detected by automated or reviewed comparisons.

## NFR-010-SC02 — Preserve validation JSON behavior

**Given** a pre-modernization validation report snapshot exists,  
**When** a dependency or framework upgrade is evaluated,  
**Then** unintentional diagnostic and serialization differences are flagged before release.
