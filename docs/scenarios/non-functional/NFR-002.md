# NFR-002 — Require no external service for imports

**Requirement:** [NFR-002](../../requirements/non-functional.md)  
**Tracking issue:** [#42](https://github.com/infoconex/RecordSift/issues/42)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Pending Windows CI for the dedicated restricted-process acceptance gate.

## NFR-002-SC01 — Import offline

**Given** CSV and XLSX fixtures are available locally and no network or database services are accessible,  
**When** import and validation run,  
**Then** all supported core operations complete without external service dependencies.

## NFR-002-SC02 — Do not trigger network requests

**Given** the default import configuration is used in a network-isolated test environment,  
**When** records are imported,  
**Then** no external service credentials or network access are required.

## Verification notes

The Windows .NET Framework 4.8 workflow runs real CSV and XLSX typed-import acceptance tests with a Windows Firewall outbound-block rule restricted to `nunit3-console.exe` and NUnit's `--inprocess` mode. The runner confirms an enabled firewall profile and the installed block rule, and removes the rule in a `finally` block. All package restoration and builds occur *before* isolation. This verifies that both import routes succeed without outbound access from the test process; it does not establish packet-level absence of attempted connections by transitive libraries, and it does not certify a machine-wide air gap. Source inspection found no HTTP, database, authentication, cloud or Office service dependency in the import path. The runner itself is network-connected for CI orchestration.

Follow the [testing strategy](../../testing/strategy.md). Record the executable test or reviewed procedure and observed evidence separately for each scenario in [traceability](../../testing/traceability.md). Scenarios for future modernized targets cannot be declared verified on the initial .NET Framework baseline.
