# FR-035 — Export validation results as JSON

**Requirement:** [FR-035](../../requirements/functional.md)  
**Tracking issue:** [#36](https://github.com/infoconex/RecordSift/issues/36)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## FR-035-SC01 — Serialize a completed validation report

**Given** a completed result includes counts and diagnostics,  
**When** JSON reporting is invoked,  
**Then** a JSON document contains stable expected fields, values, and diagnostic order.

## FR-035-SC02 — Generate reports without re-reading source

**Given** the original input is no longer available but a completed result object exists,  
**When** a report is generated,  
**Then** serialization succeeds using only the in-memory result.

## FR-035-SC03 — Avoid sensitive source values

**Given** input contains sensitive field data that appears in invalid records,  
**When** JSON diagnostics are serialized with default settings,  
**Then** raw source values and absolute file paths are not emitted.
