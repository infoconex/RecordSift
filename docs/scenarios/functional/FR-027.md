# FR-027 — Return successfully validated records

**Requirement:** [FR-027](../../requirements/functional.md)  
**Tracking issue:** [#28](https://github.com/infoconex/RecordSift/issues/28)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## FR-027-SC01 — Return only valid records in source order

**Given** an input contains valid rows interspersed with invalid rows,  
**When** import completes in continue-on-error mode,  
**Then** accepted records are returned in original order and rejected rows are excluded.

## FR-027-SC02 — Return empty accepted collection for entirely invalid source

**Given** every input row fails one or more required validation rules,  
**When** import completes,  
**Then** no invalid record appears in the accepted results while diagnostics remain available.
