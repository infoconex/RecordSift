# FR-018 — Validate type conversions

**Requirement:** [FR-018](../../requirements/functional.md)  
**Tracking issue:** [#13](https://github.com/infoconex/RecordSift/issues/13)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## FR-018-SC01 — Report malformed numeric or date input

**Given** a field contains text that cannot be converted to its declared numeric or date type,  
**When** conversion occurs,  
**Then** a field and source-specific conversion error is recorded while other valid rows remain importable.

## FR-018-SC02 — Preserve valid typed values

**Given** a source field contains valid numeric or date data in the configured culture,  
**When** conversion occurs,  
**Then** no type-conversion error is reported and the typed value is preserved.
