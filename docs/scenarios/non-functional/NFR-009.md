# NFR-009 — Avoid unnecessary platform-specific components

**Requirement:** [NFR-009](../../requirements/non-functional.md)  
**Tracking issue:** [#49](https://github.com/infoconex/RecordSift/issues/49)  
**Priority:** Must — release 0.1 quality requirement for Windows and .NET Framework 4.8 only.  
**Specification status:** Maintained — normative behavior; per-scenario verification and observed CI evidence are recorded in the [traceability matrix](../../testing/traceability.md).

**Release 0.1 requirement:** RecordSift shall operate on its supported Windows/.NET Framework 4.8 platform without requiring unnecessary OS-specific integration components when managed alternatives are available. Direct platform dependencies must be justified, and import paths must not require Microsoft Excel/Office automation, COM automation or native executable integration.

## NFR-009-SC01 — Review platform dependencies

**Given** the Windows/.NET Framework 4.8 baseline is built with the selected third-party packages,  
**When** dependencies and APIs are inspected,  
**Then** unnecessary Windows-only integration points are identified and documented, or the absence of such integrations is evidenced by a repeatable review.

## Future consideration — not a release 0.1 acceptance scenario

The former `NFR-009-SC02` proposed verifying a modern cross-platform migration. It has been **withdrawn from release 0.1 scope**; the identifier is retired and must not be reassigned. The historical Given/When/Then text and decision are preserved in the [platform-dependency review](../../engineering/platform-dependencies-net48.md).

Linux, macOS, portable target frameworks, and multi-OS test execution are **not committed requirements** for this Windows-only release. They may be considered later through a separately approved requirement and release scope. No current implementation or verification obligation follows from this historical proposal.

## Verification notes

Release 0.1 **SC01 review procedure and observed findings** are recorded in the [net48 platform dependency review](../../engineering/platform-dependencies-net48.md). The review inspected production sources, all five production project dependency graphs and pinned packages, plus the existing Windows Office-free checks and architecture-validation script executed in the Ubuntu documentation workflow. No unnecessary first-party Windows-only integration was found in the reviewed import paths. This is a manual dependency inspection supported by existing executable Windows/architecture checks, not a multi-OS runtime certification.

**Acceptance decision:** NFR-009-SC01 was reviewed and verified manually for the supported Windows/net48 target. The historical SC02 portability proposal is outside release 0.1 scope and does not block closing issue #49. Review evidence and Windows CI results are recorded in [traceability](../../testing/traceability.md).

Follow the [testing strategy](../../testing/strategy.md). Record the executable test or reviewed procedure and observed evidence separately for each scenario in [traceability](../../testing/traceability.md). Any later platform expansion requires its own approved requirements and platform-specific evidence; it is not part of this requirement.
