# FR-034 — Support streaming large datasets

**Requirement:** [FR-034](../../requirements/functional.md)  
**Tracking issue:** [#35](https://github.com/infoconex/RecordSift/issues/35)  
**Priority:** Future  
**Verification status:** Planned — executable tests have not been implemented.

## Purpose

Large CSV imports can exceed reasonable memory if every intermediate value is buffered.

## Functional requirement

**RecordSift shall:** Provide an optional streaming import approach with bounded working memory.

## Inputs and outputs

- **Inputs:** A potentially large source and a consumer/processing API capable of incremental records.
- **Outputs:** Records or diagnostics available incrementally without retaining the whole input unnecessarily.

## Functional rules

- Avoid memory use growing linearly with total record count for genuinely streaming sources.
- Honor resource limits and cancellation where supported.
- Preserve ordering and source locations in incremental results.
- Report late source or record failures without pretending all records succeeded.

## Dependencies and scope

- **Related requirements:** [FR-001](FR-001.md), [FR-027](FR-027.md), [FR-029](FR-029.md), [FR-032](FR-032.md), [NFR-007](../non-functional/NFR-007.md).
- **Boundary:** Future scope; XLSX libraries may materialize entire workbooks and do not automatically satisfy this requirement.

## Open design decisions

Set measurable working-memory budgets and choose backpressure/consumer lifetime semantics.

## Acceptance scenarios

### FR-034-SC01 — Bound memory while processing large CSV

**Given** a large CSV input is supplied to a streaming API,  
**When** records are consumed progressively,  
**Then** memory does not scale linearly with the full input size under a documented measurement budget.

### FR-034-SC02 — Handle malformed late record

**Given** streaming input contains a malformed record after many valid records,  
**When** the parser reaches that record,  
**Then** a structured diagnostic reports the late failure while honoring configured error policy.
