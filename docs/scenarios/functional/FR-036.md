# FR-036 — Expose structured in-memory results

**Requirement:** [FR-036](../../requirements/functional.md)  
**Tracking issue:** [#37](https://github.com/infoconex/RecordSift/issues/37)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## FR-036-SC01 — Expose accepted records and diagnostics

**Given** an import completes with valid and invalid source records,  
**When** the caller reads the result object,  
**Then** typed accepted records, diagnostic details, and aggregate counts are accessible without parsing JSON.

## FR-036-SC02 — Preserve result consistency

**Given** a record contains multiple diagnostics,  
**When** the result is inspected,  
**Then** invalid record count counts the row once while error count reflects individual errors.
