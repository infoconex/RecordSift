# NFR-008 — Never execute spreadsheet macros or input code

**Requirement:** [NFR-008](../../requirements/non-functional.md)  
**Tracking issue:** [#48](https://github.com/infoconex/RecordSift/issues/48)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-008-SC01 — Import a macro-bearing or formula-bearing workbook safely

**Given** a workbook contains formulas or code-like content,  
**When** its supported cell data is read,  
**Then** macros and external commands are not executed.

## NFR-008-SC02 — Do not evaluate arbitrary input-provided code

**Given** a file contains an expression or script-like string,  
**When** import runs,  
**Then** the string is treated as data under the documented read policy rather than executed.
