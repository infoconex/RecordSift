# FR-008 — Provide extensible input format interfaces

**Requirement:** [FR-008](../../requirements/functional.md)  
**Tracking issue:** [#11](https://github.com/infoconex/RecordSift/issues/11)  
**Priority:** Future  
**Verification status:** Planned — executable tests have not been implemented.

## FR-008-SC01 — Use a custom record reader

**Given** a third-party reader conforms to the published reader interface,  
**When** the import pipeline consumes its records,  
**Then** mapping and validation use the same result and diagnostic contracts.

## FR-008-SC02 — Handle reader failures

**Given** a custom reader reports an input error,  
**When** the pipeline receives that error,  
**Then** the error is represented as a source failure without being mistaken for a valid row.
