# FR-006 — Configure CSV text encoding

**Requirement:** [FR-006](../../requirements/functional.md)  
**Tracking issue:** [#3](https://github.com/infoconex/RecordSift/issues/3)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

### FR-006-SC01 — Decode a configured legacy encoding

**Given** a CSV fixture is encoded using an explicitly supported non-UTF-8 encoding,  
**When** the corresponding encoding is configured,  
**Then** non-ASCII characters are decoded and imported correctly.

### FR-006-SC02 — Detect invalid bytes according to policy

**Given** CSV bytes are invalid for a configured strict decoder,  
**When** import is attempted,  
**Then** an actionable source decoding failure is reported instead of silently corrupting data.
