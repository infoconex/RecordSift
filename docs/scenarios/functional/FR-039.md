# FR-039 — Provide custom report formatting

**Requirement:** [FR-039](../../requirements/functional.md)  
**Tracking issue:** [#40](https://github.com/infoconex/RecordSift/issues/40)  
**Priority:** Future  
**Verification status:** Planned — executable tests have not been implemented.

## FR-039-SC01 — Invoke a registered report formatter

**Given** a custom formatter is registered and a completed result exists,  
**When** report output is requested,  
**Then** the formatter receives the existing result and produces the configured format without re-importing.

## FR-039-SC02 — Handle formatter failure

**Given** a custom formatter reports a formatting problem,  
**When** report output is requested,  
**Then** the reporting failure is surfaced clearly without losing the original import result.
