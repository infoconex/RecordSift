# FR-034 — Support streaming large datasets

**Requirement:** [FR-034](../../requirements/functional.md)  
**Tracking issue:** [#35](https://github.com/infoconex/RecordSift/issues/35)  
**Priority:** Future  
**Verification status:** Planned — executable tests have not been implemented.

## FR-034-SC01 — Bound memory while processing large CSV

**Given** a large CSV input is supplied to a streaming API,  
**When** records are consumed progressively,  
**Then** memory does not scale linearly with the full input size under a documented measurement budget.

## FR-034-SC02 — Handle malformed late record

**Given** streaming input contains a malformed record after many valid records,  
**When** the parser reaches that record,  
**Then** a structured diagnostic reports the late failure while honoring configured error policy.
