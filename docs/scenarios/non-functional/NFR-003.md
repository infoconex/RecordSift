# NFR-003 — Do not require Microsoft Excel installation

**Requirement:** [NFR-003](../../requirements/non-functional.md)  
**Tracking issue:** [#43](https://github.com/infoconex/RecordSift/issues/43)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-003-SC01 — Read XLSX without Excel

**Given** a clean Windows test runner has no Microsoft Office installed,  
**When** a supported XLSX fixture is imported,  
**Then** records and diagnostics are produced successfully.

## NFR-003-SC02 — Avoid Office automation

**Given** the Excel reader is reviewed and its clean-runner integration test runs,  
**When** the workbook is processed,  
**Then** the implementation has no COM automation or Excel executable dependency.
