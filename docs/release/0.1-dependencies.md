## Security audit evidence

The initial integration Windows run #41235329070 passed its pinned package and NuGet audit job. CI rejects vulnerability warning codes NU1900–NU1905; an audit pass is dated evidence rather than a permanent guarantee. Repeat on the actual release-promotion candidate and inspect any advisory failures. The existing tests cover bounded input, Office-free XLSX, offline processing, deterministic results and safe diagnostic redaction. An additional manual credential/secret review must precede public release. Treat caller-provided source identifiers, field names and worksheet metadata as potentially sensitive; reports do not automatically scrub arbitrary metadata.
