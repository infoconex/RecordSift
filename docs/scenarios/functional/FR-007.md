# FR-007 — Read fixed-width text files

**Requirement:** [FR-007](../../requirements/functional.md)  
**Tracking issue:** [#7](https://github.com/infoconex/RecordSift/issues/7)  
**Priority:** Future  
**Verification status:** Planned — executable tests have not been implemented.

### FR-007-SC01 — Map fields by offset and length

**Given** a fixed-width fixture and schema define field offsets and widths,  
**When** a record is imported,  
**Then** fields map to their intended values without silently trimming significant characters.

### FR-007-SC02 — Report undersized records

**Given** a fixed-width record is shorter than a required field extent,  
**When** import is attempted,  
**Then** a row-specific structural diagnostic is returned.
