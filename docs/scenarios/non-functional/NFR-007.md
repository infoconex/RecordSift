# NFR-007 — Enforce configurable input resource limits

**Requirement:** [NFR-007](../../requirements/non-functional.md)  
**Tracking issue:** [#47](https://github.com/infoconex/RecordSift/issues/47)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-007-SC01 — Enforce a configured maximum

**Given** the input exceeds a documented file, row, or supported workbook limit,  
**When** import runs with that limit,  
**Then** processing fails predictably with a limit-specific diagnostic rather than unbounded consumption.

## NFR-007-SC02 — Accept input at an inclusive limit

**Given** a source meets but does not exceed a configured bound,  
**When** import runs,  
**Then** no limit error is returned solely because of the boundary value.
