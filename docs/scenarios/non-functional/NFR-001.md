# NFR-001 — Keep the public API straightforward

**Requirement:** [NFR-001](../../requirements/non-functional.md)  
**Tracking issue:** [#41](https://github.com/infoconex/RecordSift/issues/41)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-001-SC01 — Compile a minimal import example

**Given** a new consumer uses documented public configuration, import, and result types,  
**When** the sample is compiled against the target framework,  
**Then** an import can be expressed without internal-type access or undocumented initialization.

## NFR-001-SC02 — Reject ambiguous usage

**Given** a caller supplies conflicting or incomplete configuration,  
**When** the public API is invoked,  
**Then** errors are explicit and actionable rather than producing surprising silent defaults.
