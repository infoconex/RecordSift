# FR-005 — Select Excel worksheets

**Requirement:** [FR-005](../../requirements/functional.md)  
**Tracking issue:** [#18](https://github.com/infoconex/RecordSift/issues/18)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## Purpose

A workbook may contain unrelated sheets; applications need predictable selection.

## Functional requirement

**RecordSift shall:** Allow selecting the worksheet used for XLSX import.

## Inputs and outputs

- **Inputs:** A workbook and an explicit sheet selector.
- **Outputs:** Only the selected sheet's records, or an actionable selection failure.

## Functional rules

- Import exactly the requested worksheet.
- Do not silently select a different worksheet if the requested one is absent.
- Preserve the selected sheet name in row diagnostics.
- Keep sheet selection separate from schema binding and validation.

## Dependencies and scope

- **Related requirements:** [FR-002](FR-002.md), [FR-009](FR-009.md), [FR-028](FR-028.md).
- **Boundary:** Importing and combining every workbook sheet is outside this requirement.

## Open design decisions

Define whether sheet selection uses names, indexes, or both; clarify treatment of hidden and empty sheets.

## Acceptance scenarios

### FR-005-SC01 — Import a selected sheet

**Given** an XLSX workbook contains at least two sheets with distinct records,  
**When** a named worksheet is selected,  
**Then** only the selected worksheet contributes records and each diagnostic names that sheet.

### FR-005-SC02 — Report a nonexistent worksheet

**Given** a workbook does not contain the requested worksheet,  
**When** that worksheet is selected,  
**Then** import fails clearly rather than importing another sheet.
