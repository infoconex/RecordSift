# FR-003 — Configure CSV delimiters

**Requirement:** [FR-003](../../requirements/functional.md)  
**Tracking issue:** [#10](https://github.com/infoconex/RecordSift/issues/10)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

### FR-003-SC01 — Use a semicolon delimiter

**Given** a semicolon-delimited CSV fixture includes a quoted semicolon,  
**When** the importer is configured with ';' as delimiter,  
**Then** columns parse correctly and the quoted semicolon stays inside its value.

### FR-003-SC02 — Reject an invalid delimiter configuration

**Given** the delimiter setting is unsupported or ambiguous,  
**When** import configuration is validated,  
**Then** the setting is rejected with a clear configuration diagnostic before importing.
