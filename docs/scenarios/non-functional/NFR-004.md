# NFR-004 — Guarantee deterministic validation results

**Requirement:** [NFR-004](../../requirements/non-functional.md)  
**Tracking issue:** [#44](https://github.com/infoconex/RecordSift/issues/44)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-004-SC01 — Repeat the same input

**Given** a fixed input and explicit schema, culture, and options are used,  
**When** the import is executed repeatedly,  
**Then** accepted record order, diagnostic order, and report content are semantically equivalent.

## NFR-004-SC02 — Ignore ambient culture differences

**Given** the operating system locale changes while explicit parsing settings remain unchanged,  
**When** the same input is processed,  
**Then** the normalized result is identical.

## Verification notes

**Observed evidence:** [Windows PR #41185832193](https://github.com/infoconex/RecordSift/actions/runs/41185832193) completed 286/286 NUnit tests (105 Domain, 48 Application, 98 CSV, 19 Reporting, 16 XLSX), including all four NFR-004 tests. [Documentation PR #41185832283](https://github.com/infoconex/RecordSift/actions/runs/41185832283) passed. Both scenarios are Automated in traceability; the specification planning label remains unchanged by documentation policy.

Real CSV integration acceptance uses explicit `fr-FR` parsing and a semicolon-separated input containing accepted, duplicate-key, out-of-range, custom-rule, and conversion-rejected records. Eight fresh imports assert accepted ordering, ordered diagnostic codes and logical/physical coordinates, as well as identical JSON and readable reporting. A second integration test compares equivalent imports under `en-US`, `fr-FR`, and `de-DE` process and UI cultures, restoring both in `finally`. Two further XLSX tests repeat real ExcelDataReader imports and verify stable records/diagnostics across ambient culture changes. These tests do not claim that arbitrary caller-supplied nondeterministic mapping delegates or predicates can be made deterministic.
