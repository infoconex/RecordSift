# FR-032 — Support cancellation

**Requirement:** [FR-032](../../requirements/functional.md)  
**Tracking issue:** [#33](https://github.com/infoconex/RecordSift/issues/33)  
**Priority:** Should  
**Verification status:** Planned — executable tests have not been implemented.

## FR-032-SC01 — Honor cancellation during import

**Given** a cancellation request arrives while records are being processed,  
**When** the operation checks cancellation,  
**Then** processing stops with an explicit canceled outcome, not a success summary.

## FR-032-SC02 — Complete without cancellation

**Given** no cancellation is requested during a valid import,  
**When** import completes,  
**Then** all valid rows are returned normally.
