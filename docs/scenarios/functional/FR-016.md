# FR-016 — Support custom field conversion

**Requirement:** [FR-016](../../requirements/functional.md)  
**Tracking issue:** [#5](https://github.com/infoconex/RecordSift/issues/5)  
**Priority:** Should  
**Verification status:** Planned — executable tests have not been implemented.

## FR-016-SC01 — Invoke a registered converter

**Given** a configured custom converter handles a supported source field,  
**When** the field is imported,  
**Then** the converter result is assigned to its target property.

## FR-016-SC02 — Report custom conversion failure

**Given** a registered converter rejects an invalid source value,  
**When** import runs,  
**Then** a structured field-specific diagnostic is returned without corrupting other records.
