# NFR-004 — Guarantee deterministic validation results

**Requirement:** [NFR-004](../../requirements/non-functional.md)  
**Tracking issue:** [#44](https://github.com/infoconex/RecordSift/issues/44)  
**Priority:** Must — release 0.1 quality requirement (later-platform scenarios remain future milestones).  
**Verification status:** Planned — no executable checks have run.

## NFR-004-SC01 — Repeat the same input

**Given** a fixed input and explicit schema, culture, and options are used,  
**When** the import is executed repeatedly,  
**Then** accepted record order, diagnostic order, and report content are semantically equivalent.

## NFR-004-SC02 — Ignore ambient culture differences

**Given** the operating system locale changes while explicit parsing settings remain unchanged,  
**When** the same input is processed,  
**Then** the normalized result is identical.
