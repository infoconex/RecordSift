# FR-020 — Validate numeric and date ranges

**Requirement:** [FR-020](../../requirements/functional.md)  
**Tracking issue:** [#21](https://github.com/infoconex/RecordSift/issues/21)  
**Priority:** Must  
**Verification status:** Planned — executable tests have not been implemented.

## Purpose

Numeric and date boundaries constrain acceptable domain data beyond type correctness.

## Functional requirement

**RecordSift shall:** Validate numeric/date fields against declared inclusive or exclusive bounds.

## Inputs and outputs

- **Inputs:** Converted numeric/date value and configured lower/upper bounds.
- **Outputs:** A range validation diagnostic or successful boundary validation.

## Functional rules

- Evaluate range rules only after successful type conversion.
- Respect whether each configured bound is inclusive or exclusive.
- Report out-of-range values with source and field provenance.
- Do not conflate invalid value formats with out-of-range values.

## Dependencies and scope

- **Related requirements:** [FR-011](FR-011.md), [FR-018](FR-018.md), [FR-028](FR-028.md).
- **Boundary:** Cross-field comparisons belong to FR-024 and are not implied by single-field ranges.

## Open design decisions

Resolved by [ADR 0027](../../engineering/decisions/0027-domain-typed-range-validation.md): Domain range rules evaluate successfully converted CLR values using decimal numeric comparisons and DateTime comparisons with no inferred time-zone conversion; both inclusive and exclusive endpoints are explicit. Callers must supply comparably normalized dates when time zones matter.

## Acceptance scenarios

### FR-020-SC01 — Report out-of-range values

**Given** numeric and date fields fall outside their configured accepted ranges,  
**When** validation runs,  
**Then** each out-of-range field receives the corresponding structured diagnostic.

### FR-020-SC02 — Accept values on inclusive boundaries

**Given** a field equals a configured inclusive minimum or maximum,  
**When** validation runs,  
**Then** no range diagnostic is raised.
